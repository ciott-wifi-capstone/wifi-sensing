# References and code sources

The project modules were adapted from the static research notebook,
static/SQI scripts and motion analysis scripts. The original sources remain
in the research archive. The maintained modules and their sources are listed
in [NAME_MAP.md](NAME_MAP.md).

## Methods and external software

- **FarSense**: Y. Zeng, D. Wu, J. Xiong, E. Yi, R. Gao and D. Zhang,
  *FarSense: Pushing the Range Limit of WiFi-based Respiration Sensing with CSI
  Ratio of Two Antennas*, IMWUT 3(3), 121, 2019.
  [Paper](https://doi.org/10.1145/3351279),
  [author manuscript](https://arxiv.org/abs/1907.03994).
  The estimator is adapted from the local FarSense-style code listed below,
  rather than an official release from the paper authors.
  Local source: `external/farsense/farsense_single_end.py`
  SHA-256: `8420d34083b0778a763253cd71a13d5fe5f0b53324364c3ac0b263456dacaae3`.
  Six numerical functions were retained; old data loaders, plotting/demo main
  and the unused `wifilib` dependency were removed from the supported path.
  The sampling rate is an explicit argument instead of shared mutable globals.
- **VitalCSI**: T. Michaelis, J. Jorge, N. Bijlani and M. Villarroel,
  *VitalCSI: Contactless Respiratory Rate Estimation Using Consumer-Grade Wi-Fi
  Channel State Information*, Sensors 26(1), 225, 2026.
  [Paper](https://doi.org/10.3390/s26010225).
  SQI is a project adaptation of quality concepts, not the paper's complete
  implementation. The time-domain extrema counter is explicitly not BSSF.
  The supplied `wical_sqi.py` v1.0.1 is the source for `src/wical/sqi.py`.
- **WiCAL**: F. Wang, Z. Li, R. Xiong, T. Mi and R. C. Qiu,
  *WiCAL: Accurate Wi-Fi-Based 3D Localization Enabled by Collaborative Antenna
  Arrays*, IEEE JSAC 43(11), 3752–3765, 2025.
  [Paper](https://doi.org/10.1109/JSAC.2025.3584540),
  [author manuscript](https://arxiv.org/abs/2505.21408).
  WiCAL provides the switched-array platform used for the respiration
  experiments and observation-selection study.
- **Intel CSI tooling**: D. Halperin et al., *Tool Release: Gathering 802.11n
  Traces with Channel State Information*, 2011.
  [Documentation](https://dhalperi.github.io/linux-80211n-csitool/).
  The supported PicoScenes reader is the separately installed `csiread` 1.4.1
  dependency. No driver, radio firmware or binary is redistributed here.
- NumPy, SciPy and Matplotlib remain third-party dependencies with their own
  licenses. Their code is installed separately.

The original authorship and redistribution permission for the local estimator
source remain unconfirmed. This package does not grant a project-wide reuse
license. Attribution to the underlying methods is retained above.

## Motion result provenance

The motion tables are regenerated by `scripts/analyze_motion.py` using the
original event aggregation and similarity calculation from
`analyze_new_motion_spatial_fingerprints.py`. They are byte-identical to the
original `motion/spatial_fingerprint/` exports:

| Table | SHA-256 |
| --- | --- |
| run_spatial_fingerprints.csv | 6918285374b2880208f729c9a745afe8b8a7e739f85eb01e1058f5a5ce739608 |
| run_pair_similarity.csv | 7f2279617aea05c2f88188e431dc214b29141bd37cfc6938d3689280c768da9b |
| action_similarity.csv | 78b83f168ec2ea7053d0acee8d1936073d496b7cadd2e9fe6606cf2742470091 |

The two bundled motion figures are generated from these run features and
correlations. They show responses around CSI-detected candidates. The candidates have no
independent motion labels and are not used to evaluate respiration accuracy.
